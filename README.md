# AYANFE AI V2

AYANFE AI is a modern general-purpose AI assistant and learning companion.

## Creator

Ayanfe

## Main systems

- AI assistant
- Education
- Live information
- Web search
- Conversation memory
- Multiple chats
- YouTube search
- File handling
- Voice support
- Streamlit interface

## Deployment

Target platform: Streamlit Community Cloud

## API Security

The Gemini API key must never be placed directly inside public source code.

Use Streamlit Secrets for deployment:

GEMINI_API_KEY = "your-key"
